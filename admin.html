    토큰은 어떻게 만들어요?
    1. GitHub 토큰 만들기 페이지를 열어요. (GitHub 로그인 필요)
    2. Token name: 아무 이름이나 (예: 마음정원 관리자)
    3. Expiration: 사용할 기간 (예: 90일 또는 1년)
    4. Repository access: Only select repositories → SEL 선택
    5. Permissions → Repositories에서 Add permissions → Contents를 고르고 Read and write로 바꿔요.
    6. 맨 아래 Generate token → 나온 글자를 복사해서 위 칸에 붙여 넣고 연결하기.

    ⚠️ 토큰은 비밀번호처럼 다뤄 주세요. 이 기기에만 저장되고, 공용 PC에서 썼다면 토큰 지우기를 눌러 주세요.
