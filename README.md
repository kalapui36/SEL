# 🌱 마음이 자라는 교실

AI와 함께하는 사회정서교육(SEL) 교사학습공동체의 웹앱 모음 대문 페이지입니다.

## 파일 구성

| 파일 | 역할 | 수정 빈도 |
|---|---|---|
| `apps.js` | **앱 목록** (이름, 설명, 주소, 역량 등) | 자주 — 앱 추가/수정은 여기서만 |
| `index.html` | 대문 문구, 우리 이야기, 푸터 | 가끔 — `✏️` 표시된 곳 |
| `style.css` | 색·글꼴·레이아웃 | 거의 안 함 |
| `script.js` | 카드 그리기·필터 동작 | 안 건드려도 됨 |

## 앱 추가하는 법

`apps.js`의 `APPS` 목록에 아래 덩어리를 하나 복사해 붙이고 내용만 바꾸면 됩니다.

```js
{
  name: "앱 이름",
  emoji: "🌈",
  desc: "한 줄 소개",
  url: "https://앱주소",
  heart: ["self"],        // self / manage / social / relation / decide 중 1개 이상
  grade: "5-6학년",
  scene: "아침 활동",
  maker: "○○○ 선생님",   // 비워도 됨
},
```

## 다섯 가지 마음 (CASEL 5대 역량)

| key | 아이들 말 | 역량 |
|---|---|---|
| `self` | 🌱 나를 알아요 | 자기인식 |
| `manage` | 🌿 나를 다독여요 | 자기관리 |
| `social` | 🌼 너를 느껴요 | 사회적 인식 |
| `relation` | 🌷 함께 지내요 | 관계 기술 |
| `decide` | 🌳 바르게 골라요 | 책임 있는 의사결정 |
